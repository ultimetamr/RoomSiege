# 皮肤图片刷新与结算页遮挡修复（2026-11-04）

原因：武器研发卡、四武器阵容卡和建造栏只按武器 ID 读取基础图片，未使用穿戴皮肤 ID；武器研发的模型预览也强制传入空皮肤。结算页的军械商店按钮（叠加页面坐标后中心 -201）与金评级外观按钮（中心 -216，高36）存在交叠。

改动：
- 共享 WeaponArtwork 按皮肤 ID 读取对应图片，缺图时回退基础图。商店、阵容、建造栏和塔图鉴使用该入口。
- 建造栏同时跟踪武器和皮肤，允许配置阶段更换同一武器的皮肤后立即刷新图片。保留本局锁定后的实际配置。
- 武器研发预览显示已穿戴皮肤，换肤默认定位已穿戴款式。
- 皮肤按钮改为“穿戴”/“已穿戴”，提示改为“皮肤已穿戴”；恢复基础全息有对应提示。
- 结算统计与核心碎片奖励分行，重开、主菜单、商店、金评级外观各自留出间距。
- 阵容页底部说明改为一行，与分页按钮保持间距。

检查：专项测试 3/3 通过。覆盖54款皮肤图片资源、缺图回退、穿戴持久化、还原基础外观、商店及阵容图片/模型、建造前换肤刷新、锁定后不可更换、胜负结算控件边界与文字高度、结算打开商店和重开。
