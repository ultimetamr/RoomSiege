# RoomSiege 游戏 UI 统一 · 2026-11-04

## 视觉与层级

采用深蓝面板、青蓝选中态、暖金货币、低饱和辅助文字。统一 10px 圆角、细分隔线、固定标题栏与底部消息区。稀有度色只用于皮肤标识。世界空间面板尺寸与跟随策略保持原样。

军械库采用六个固定导航页：武器研发、全息皮肤、战术补给、四武器阵容、携行装备、收藏挑战。余额固定右上角；武器及皮肤采用左列表、右模型与说明、底部主要操作。补给采用三列等宽卡；阵容及携行采用左右选择；挑战采用两列奖励卡。

主菜单保留对决图，加入左侧渐变阅读遮罩。档案、结算、设置、暂停、帮助、局内强化采用统一标题栏和按钮。建造栏使用简短中文武器名，减少皮肤说明与价格挤压。

## 边界

只改 UI 及其回归测试，不改变战斗平衡、房间扫描、存档字段、购买与穿戴规则、携行限制。保留页面互斥、释放后返回、射线高亮、按下防穿透、放置时收起面板。
