# 世界空间 UI 清晰度修复

日期：2026-11-05。

## 检查发现

- 主面板和扫描面板创建了 CanvasScaler，却没有设置动态文字像素密度，保持默认 1。实际安装的 uGUI Text 使用 Canvas.scaleFactor 生成动态字形；原先 16–32 单位的文字缺少放大后的采样余量。
- 商店和图鉴另建了覆盖排序 Canvas，需要一起设置字形采样，防止主界面清楚而子页面仍模糊。
- 圆角玻璃面板的外沿直接截断，没有透明抗锯齿过渡。
- 项目已有 4x MSAA 的 High Fidelity 管线，但 Android 默认质量没有明确记录；另外两档管线是 1x，不能依赖平台默认选择。

## 修改

- WorldUiSampling 为主面板、扫描、商店和图鉴设置 3x 动态字形采样，保持原字号、物理尺寸和按钮命中区域。
- RoundedGlassImage 将圆角细分从每角 8 段提高到 12 段，增加 1 个 Canvas 单位宽的透明边缘过渡。网格保持在原矩形内，继续继承 Image，兼容按钮和抓取逻辑。
- Android 默认质量明确指定 High Fidelity（索引 2），采用已有 4x MSAA 管线，不提高整体眼缓冲分辨率。
- 启动日志输出字形密度、质量档位、当前管线和相机 MSAA 开关，供真机核对。
- 本次构建继续使用全解锁试玩配置；正式工程的购买配置不变。

## 验证

- 原有 21 项世界面板、导航和全商店页面布局检查通过；新增 3 项字形采样、透明边缘及 Android 抗锯齿配置检查通过。
- 覆盖排序子页面的 Text.pixelsPerUnit 确认是 3，关闭再打开仍保持；字号、物理布局和按钮命中范围不变。
