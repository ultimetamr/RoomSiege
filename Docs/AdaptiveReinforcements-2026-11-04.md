# 全武器 / 持续道具三选一强化

## 生效规则

第 3、6、9 波清场后各选一次；选择期间暂停战斗及道具时钟，选择后恢复 15 秒准备期。候选对象来自场上尚未移除、尚未消耗的武器，以及仍生效的持续道具 / 塔超载。已售出武器、已过期法阵、已引爆地雷、未使用库存不参与抽取。

全部 18 种武器和 12 种道具各有 3 类选项，共 90 种对象强化。优先显示不同对象，武器和持续道具同时存在时至少各显示一项；只有一个有效对象时显示该对象的三个方向。没有有效对象时提供 40 金币、战术冰冻冷却 ×0.8、战术冰冻时长 +0.5 秒三种核心支援，防止卡住。

同类现有及后续新建武器共享强化；同类道具再次使用继承强化。新开一局清零，不修改商店皮肤、武器等级、持久库存和配置资产。每次点击只生效一次，过期的选择不能触发下一波或清理敌人。

## 武器强化

所有武器的覆盖扩展：射程 / 作用半径 ×1.15。

效能强化：
- 作战武器：伤害 ×1.25。
- 冰墙 / 引力井：减速 +5 个百分点，上限 80%；Boss 仍按原控制抗性处理。
- 战术信标 / 棱镜中继：主光环增益 ×1.25。
- 寒霜发生器：每脉冲寒霜 +1 层。
- 蚀甲投射器：破甲 +10 个百分点，上限 90%，Boss 减半。
- 电磁压制器：削盾 +10 个百分点，上限 95%。

专属进阶：
- 机枪 / 磁轨狙击 / 环刃哨卫：攻速 ×1.20。
- 寒霜发生器：脉冲频率 ×1.20。
- 激光 / 特斯拉 / 贯星轨道炮：命中目标上限 +1。
- 迫击炮 / 追踪导弹：爆炸半径 ×1.20。
- 陷阱：触发返还原造价 +15 个百分点，累计上限 60%，不含升级投入。
- 冰墙 / 引力井：离场减速 +1 秒。
- 战术信标：附近作战塔另获射程 +5 个百分点。
- 棱镜中继：附近作战塔另获攻速 +5 个百分点。
- 蚀甲投射器：破甲持续 +1 秒。
- 电磁压制器：召唤干扰 +1 秒，Boss 增量减半。
- 蜂巢霰弹：扇形半角 +10 度。
- 熔流喷焰：余焰 +1 秒。

## 道具强化

所有道具持续 / 守候时间 +15 秒，现有未耗尽效果立即延长；已过期效果不会复活。

覆盖扩展：范围 ×1.15；紧急维修改为后续脉冲间隔 ×0.80，超载电池改为额外射程 +10 个百分点。

效能强化：
- 急冻脉冲：减速 +5 个百分点、普通敌人每次短冻 +0.5 秒；Boss 短冻保持原上限。
- 电磁干扰：削盾 +3 个百分点，上限 99%；减速 +5 个百分点。
- 超载电池：输出倍率 +0.25、控制额外 +5 个百分点。
- 诱饵信标：减速 +5 个百分点，上限 80%。
- 紧急维修：维修量 ×1.25。
- 轨道打击 / 烈焰焚烧阵 / 感应爆破雷 / 雷暴裁决阵：伤害 ×1.25。
- 重力迟滞阵：Boss 减速 +5 个百分点，离阵减速保留多 1 秒；普通敌人保留 80% 上限。
- 蚀甲破防印：破甲 +5 个百分点，上限 90%。
- 寒霜封锁阵：每脉冲寒霜 +1 层。
