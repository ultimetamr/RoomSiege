# RoomSiege 视觉规范

本模块只提供配色、字号、矢量面板几何与材质细节，不持有经济、伤害、状态机或交互逻辑。

| 用途 | 色值 |
| --- | --- |
| 我方、部署格、安全区 | #4FD8FF |
| 敌方、出怪口、禁放提示 | #FF5A5A |
| 金币、已解锁的金色皮肤 | #FFD27A |
| 冰墙与减速语义 | #7AD7FF |

- 面板使用 `RoundedGlassImage : Image` 的矢量三角网格，圆角半径 16 个 Canvas 单位；现有面板的单位为像素。细描边宽 1.25px。
- 玻璃底色 alpha 0.20、卡片 0.17、按钮 0.28、弹层 0.42；描边和轻微上部提亮提供玻璃质感。背景可透过，不复制或模糊 Passthrough 相机画面。
- 字号只有标题 30、正文 22、注释 16 三档；关闭任意字号的自动缩放。文字使用现有动态 TTF 字体，面板、描边和进度环均无栅格 UI 贴图。
- 塔仅由发光几何线构成：MG 枪匣与双导轨、Frost 六棱冰柱、Laser 晶体与光圈、Trap 菱形触发框；等级保留三圈标识，金色皮肤保持原有解锁与装备流程。
- 全息线使用透明叠加、柔和亮芯，不依赖 HDR/Bloom；敌人使用低饱和绯红剪影、边缘提亮与局部命中闪光，受减速时仅附加冰蓝细环，读取既有减速状态。
- 沙盘家具、墙体和地板只画轮廓，实际部署模型不变。真实房间沿用现有 Passthrough。
- `Resources/RoomSiegeHoloDetail2K.png` 是实际 2048×2048 灰度全息微纹理，塔和敌人材质共用；开启 Mipmap、双线性过滤，Android 导入上限 2048。所有语义配色来自运行时样式，不烘焙到纹理。

按本次任务要求，未运行编译、测试、构建、模拟器或视觉验收。
