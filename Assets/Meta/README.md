# RoomSiege Meta/

实现本地战果、图鉴、评级、全息换色和按难度分组的本地排行榜。按用户要求，未执行测试、编译、构建、模拟器、设备或交互验收；不声明验收通过。

## 使用入口

`RoomSiege_Start` 自动启动 `MetaController`，等待现有配置、敌人池、波次与世界空间面板就绪。主屏标题栏右侧提供“图鉴 / 战果 / 排行”入口，打开同一主屏内的覆盖页；自动继承当前面板的位置跟随、距离复位和暂停淡化。

覆盖页提供“战果”“塔图鉴”“敌种图鉴”“本地排行”四页和关闭按钮。战役胜利、失败或中止后自动展示战果。打开图鉴本身不切换游戏状态或暂停战斗；原有暂停控件仍负责战斗暂停。

## 战果与评级

- 显示难度、胜负、剩余生命、漏怪数、平均 DPS、本体有效伤害、有效战斗时间、剩余金币、分数和皮肤解锁状态。
- 本体有效伤害来自 EnemyActor 在实际扣血后发出的事件，按剩余 HP 截断过量伤害。护盾伤害、未造成伤害的减速和测试桩不计入 DPS。
- DPS = 累计本体有效伤害 / 累计有效 WAVE 秒数。排除 15 秒准备期、暂停、扫描等待以及缺失有效房间的时间。Boss 召唤物正常计入。中断尝试使用已有 Waves 的结算快照一并累计。
- 漏怪统计来自每波结算快照，包含致命漏怪和召唤物；主动取消或房间切换时清除的敌人不被当成漏怪。
- 标准金评级严格要求“胜利 + 满血 + 剩余 ≥300G”。满血与 GameManager 启动时记录的 InitialLives 比较，当前工程默认为 10，不在 Meta 中硬编码。休闲和硬核暂沿用相同金评级门槛，排行榜分别保存。
- 未指定的银/铜规则：其余胜利为银，失败为铜；中止不评级、不进入排行榜、不解锁金色皮肤。

## 图鉴解锁与声音

- 塔：成功建造过该类型即解锁；卖出或陷阱消耗后仍保留发现记录。锁定图鉴不限制建造栏购买。
- 敌种：EnemyController 首次生成该类型时解锁，不需要等待击杀或通关；召唤物也可解锁同类条目。
- 四座塔展示造价、范围、完整三等级伤害/射速/持续伤害/减速/溅射/穿透/升级费、战术局限及卖出规则。现有配置没有塔 HP，图鉴明确展示无独立 HP。
- 五敌种展示基础 HP/护盾、当前难度 HP/护盾/速度/漏血、击杀奖励、行为和应对建议。只有护盾的激光克制来自当前伤害机制；其他条目是战术建议，不引入额外属性倍率。
- 解锁条目可回放当前 Audio/ 使用的真实本地声音样本：塔命中/触发/激光嗡鸣、敌种脚步。通过 AudioDirector 的空间音频路径播放，不创建敌人或塔，不改变战斗数据。如果音频模块尚未就绪，界面显示无法回放的原因。

## 金评级全息换色

任一难度获得金评级后永久解锁金色全息配色，首次解锁默认启用。覆盖页底部可切回原色或重新装备金色，选择会保存。现有塔与后续建造的塔都会更新等级环、炮口线与弹道/光束颜色，塔属性和价格保持不变。

## 本地排行榜与分数

每个难度独立保存前 10 条成绩，按分数降序、波次号降序排列。排行榜可切换休闲/标准/硬核，并分页显示每页 5 条；各难度第一条即该难度的本地最高分。胜负都记录，中止不记录；没有联网请求、登录、账号、云存储或第三方排行服务。

默认分数规则：

`max(0, 胜利奖励10000 + 完成波数×1000 + 击杀数×10 + 剩余金币 + floor(剩余生命×100) - 漏怪数×25)`

分数上限截断为 int.MaxValue。此规则只用于本地记录，不影响钱包、塔属性或游戏结果。当前战役完成回调只提交一次成绩。

## 持久化与接口

持久化全部使用 Unity PlayerPrefs（排行榜为 JSON），保存发生在首次发现、皮肤选择或结算时，不修改其他模块已有偏好：

- `RoomSiege.Meta.TowerUnlocked.<id>`
- `RoomSiege.Meta.EnemyUnlocked.<id>`
- `RoomSiege.Meta.GoldSkinUnlocked`
- `RoomSiege.Meta.GoldSkinEquipped`
- `RoomSiege.Meta.LocalScores`

`MetaController.Instance` 提供 `HasSettlement`、`Settlement`、`GoldSkinUnlocked`、`GoldSkinEquipped`、`OpenSettlement()`、`OpenCodex(bool)`、`ToggleGoldSkin()`。`MetaPersistence.GetScores(difficultyId)` 读取本地排行榜。`MetaRules` 提供评级与分数计算。

基础 GameManager 保持在 RoomSiege.Meta；新页面和聚合逻辑放在 Meta/Runtime 的独立 RoomSiege.Meta.Runtime 程序集，避免 Enemies/Waves 已依赖 GameManager 带来的循环引用。

必要接入只增加统计/展示接口：GameManager 记录初始生命；敌人报告实际本体扣血；WaveResult 附带本波伤害与有效时间并保留旧构造签名；TowerVisuals 提供纯外观换色；AudioDirector 提供图鉴声音回放。未新增玩法、敌种、波次或验证流程。
